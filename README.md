# Walker Analytics

Walker Analytics is a Python- and Streamlit-based market decision-support application created as a portfolio demonstration project.

## Current Capabilities

- Multi-asset market analysis
- EMA20 and 30/50/100/200-day moving averages
- Interactive Asset Explorer
- Early Rotation analytics
- Confirmed Rotation analytics
- Momentum scoring
- Acceleration scoring
- Rotation-state classification
- Interactive Plotly visualizations

## Architecture

Market Data

↓

Python Price / Return / Moving Average Pipeline

↓

Web Asset Snapshot

↓

Early Rotation Engine

↓

Confirmed Rotation Analytics Engine

↓

Streamlit Application

↓

Walker Analytics
